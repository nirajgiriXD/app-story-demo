# Tasky

Tasky is a small task list that runs in the browser. The videos are for new users.

## Tips for the demo

- Everything is on one page: the box to add a task at the top, the filters (All, Active,
  Done) under it, then the list, then the count of tasks left and **Clear done**.
- Use short, made-up tasks like "Book the team lunch".
- Tasks are saved in the browser, so there is no login and nothing to set up.

## Release notes

### Added
- **Add a task**: type it in the box and press **Add task**. It appears at the bottom of
  the list, highlighted for a moment.
- **Filters**: **All**, **Active** and **Done** show only those tasks.
- **Clear done**: removes every ticked task at once.
